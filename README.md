# Velkro ProClean website

Premium, responsive website concept for Velkro ProClean.

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Before client handoff
- Replace the hero background image with the supplied 10-second brand video at `public/velkro-hero.mp4` and add a poster image.
- Confirm all listed services, package prices, phone numbers and booking details with the client.
- Add the additional services once the client shares the confirmed list.
- Confirm the business's service locations and any claims/certifications before publishing.

This is a design/demo build, not a live booking or payment system.
